# Hi, I'm Agus Byna

I'm an Information Systems lecturer at Universitas Sari Mulia, based in Banjarmasin. I build practical software and developer tools, with a particular interest in making research workflows clearer and LLM-assisted work more structured.

## Selected work

- [CMRP — Canvas Model for Research Projects](https://github.com/agusbyna/cmrp): a `pi` coding-agent extension that turns an academic research canvas into a guided workspace, checks the logical links between sections, and exports to Markdown or JSON.
- [omp-laya](https://github.com/agusbyna/omp-laya): a lightweight `omp` wrapper for Laya's fast choice, scoring, and yes/no decisions, with an optional prompt pre-screen hook.

I also explore open-source work across agent tooling, research skills, and LLM developer tools. Browse [my public repositories](https://github.com/agusbyna?tab=repositories) to see more.
